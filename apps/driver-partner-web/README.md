# Driver / Partner Application (UI presentation)

Exact visual recreation of the Driver / Partner Key Modules presentation, with interactive phone screens wired to the NestJS driver APIs.

## Run

```bash
# API must be running on :3000
cd apps/driver-partner-web
cp .env.example .env
npm install
npm run dev
```

Open http://localhost:5174

Demo login: `driver@autoads.test` (requires seeded API).
