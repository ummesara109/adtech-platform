# AutoAds Advertiser Web

React + TypeScript + Vite + Tailwind advertiser dashboard.

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

Open http://localhost:5173 — set `VITE_API_BASE_URL=http://localhost:3000` to use the NestJS API.

See the root [README](../../README.md) for the full platform stack.
